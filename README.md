# Horarium — Study Command Center

## Download
Grab the latest Windows installer from the **[Releases](../../releases/latest)** page.

> **Windows SmartScreen Note:** Because Horarium is an independent release, Windows may show a blue *"Windows protected your PC"* popup on first launch. Click **More info → Run anyway** to proceed.

## Activation (Offline)
1. Install and launch **Horarium**.
2. Click **Copy** next to your **Device ID** (`HR-XXXX-XXXX-XXXX`) and send it to me.
3. Paste the license key I send back (or drag-and-drop the `.lic` file onto the window) and click **Activate**.
